# 🚀 Ruta Web con Inteligencia Artificial — Presentación Interactiva

Aplicación web moderna y de alta interacción diseñada para la enseñanza en vivo de la **Ruta Web con IA** (Clase 0: Prepara tu Entorno & Clase 1: Piensa como Dueño de una Web).

🔗 **Repositorio oficial:** [https://github.com/BrayanLP/presentacion-ruta-web-ai](https://github.com/BrayanLP/presentacion-ruta-web-ai)

---

## ✨ Características Principales

- **🎮 Modo Presentador / Keynote Inmersivo**: Oculta la barra de navegación con la tecla `H` o en pantalla completa (`F`) con auto-revelado al pasar el mouse por el borde superior.
- **🌗 Sistema de Ritmo Visual (Luz ↔ Sombra)**: Alternancia dinámica entre diapositivas claras y oscuras (tecla `C`) para evitar la fatiga visual y mantener a los alumnos activos.
- **🎨 5 Modos de Estimulación y Colores Neón**:
  - ⚡ Cyber Emerald
  - 🔮 Synthwave Hyper
  - 🌐 Electric Azure
  - 🔥 Solar Flare
  - 🌈 Aurora Spectrum
- **🔴 Puntero Láser Neón (Tecla `L`)**: Puntero láser ultra brillante de alto contraste montado en React Portal para máxima visibilidad sobre cualquier fondo o modal.
- **⚡ Botón ¡Boost de Energía! (Tecla `W`)**: Shock visual con vibración sutil, lluvia de partículas de color y sonido sintetizado.
- **🎁 Gran Sorteo en Vivo (Slide 1.8)**: Tómbola digital interactiva con sonidos, fanfarria musical y confetti para premiar a los alumnos que trajeron su anuncio/negocio.
- **📝 Generador de Brief de mi Web (Tecla `B`)**:
  - Genera automáticamente el **Prompt Maestro** para Antigravity IDE invocando al **Agente Arquitecto Frontend Senior + Especialista en SEO & GEO** con el stack: **Next.js (App Router) + GSAP + React Hook Form + Schema.org JSON-LD**.
  - Permite descargar el documento `BRIEF.md` o copiar el prompt en 1 clic.
- **✅ Checklist Interactivo de Clase 0**: Guardado en tiempo real en `localStorage` con porcentaje y fuegos artificiales al completar el 100%.

## ⌨️ Atajos de Teclado

| Tecla | Acción |
| :---: | :--- |
| **`→` / `Espacio`** | Avanzar a la siguiente diapositiva |
| **`←`** | Retroceder a la diapositiva anterior |
| **`H`** | Ocultar / Mostrar barra superior (Modo Presentación Inmersivo) |
| **`C`** | Alternar Ritmo de Contraste (Intercalado Luz ↔ Sombra) |
| **`T`** | Rotar Paleta de Acentos de Neón |
| **`L`** | Alternar Puntero Láser Neón |
| **`W`** | ¡Boost de Energía! (Shock visual y despertar alumnos) |
| **`B`** | Abrir Generador de Brief Web |
| **`P` / `N`** | Abrir / Cerrar Notas del Expositor |
| **`O`** | Abrir Vista General de Diapositivas (Mesa de Luz / Grid) |
| **`0` / `1`** | Cambiar rápidamente entre Clase 0 y Clase 1 |
| **`F`** | Alternar Pantalla Completa |
| **`?`** | Ver ventana de atajos |
| **`Esc`** | Cerrar cualquier modal |

## 🛠️ Stack Tecnológico

- **Framework**: React 19 + TypeScript + Vite
- **Estilos**: Tailwind CSS + Custom CSS Variables & Mesh Gradients
- **Animaciones**: GSAP + Web Animations API + Canvas Confetti
- **Iconos**: Lucide React
- **Audio**: Web Audio API (Chimes, Ticker, Fanfarria)

## 🚀 Instalación y Ejecución Local

```bash
# Clonar repositorio
git clone https://github.com/BrayanLP/presentacion-ruta-web-ai.git

# Entrar al directorio
cd presentacion-ruta-web-ai

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:5173/](http://localhost:5173/) en tu navegador.
